---
title: Button
description: The `pui-btn` class turns a `<button>` or an `<a>` into a button. It brings the shape only; pair it with a style and a color.
tags: [component, button]
changed: "1.0"
---

## Styles

::example
```html
<button class="pui-btn pui-solid pui-theme">Solid</button>
```
::

## Colors

::note
Two colors are defined against the page rather than against a palette.
::

::warning
An `<a>` has no `disabled` attribute.
::

::example
```html
<div class="pui-group-row"><button class="pui-btn pui-outline pui-surface">A button with a long label that makes this line of code much wider than the page</button><button class="pui-btn pui-outline pui-surface">Another</button></div>
```
::
